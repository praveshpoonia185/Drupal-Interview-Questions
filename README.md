## Interview Tips

- Be comfortable with modern Drupal (Drupal 10/11), Composer, Drush, and Twig.
- Understand Symfony concepts: services, routing, controllers, dependency injection.
- Practice creating custom modules, plugins, forms, blocks, and REST endpoints.
- Know Drupal caching, configuration management, and deployment workflows.
- For senior roles: expect architecture, performance, security, and API questions.
- For frontend roles: know Twig, Single Directory Components (SDC), libraries, preprocess functions, and responsive theming.

## How to Use

1. Clone or download this repository.
2. Read questions and answers section by section.
3. Practice coding examples in a local Drupal site (use DDEV or Lando).
4. Explain answers in your own simple words during interviews.
